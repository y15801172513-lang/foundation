# Contributing

This public repository is a reviewed distribution snapshot. Development is maintained separately; public changes are never automatically merged back.

Contributions may be proposed in a pull request for maintainer review. Please include a focused description and reproducible checks, omit private data, and preserve third-party notices. Acceptance and review times are not guaranteed. Do not upload local installation state, caches or credentials.

Project-owned code is licensed under MIT; dependencies retain their respective licenses. Changes to release assets cannot replace existing immutable versions.
