# Security

Foundation is a small local tool, provided without a security service or response-time guarantee. Maintainer: [y15801172513-lang](https://github.com/y15801172513-lang).

Do not post credentials, personal files, installation receipts or exploitable details publicly. There is currently no dedicated private vulnerability reporting channel. Before sending sensitive details, arrange a private channel with the maintainer; do not assume an issue or pull request is confidential.

Use only the fixed public repository, verified immutable releases and the documented npm namespace. Never bypass macOS security controls. Local confirmation reduces accidental actions; it does not defend against malicious processes with the same user's unrestricted filesystem access. Review the exact plan before approving changes.

Only the current stable macOS arm64 release is the intended maintenance target. Old immutable releases remain unchanged; fixes use a new version. No automatic updates are performed.
