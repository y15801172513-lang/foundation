# Support

Foundation is a small self-use tool shared without commercial support or an SLA. Start with [installation instructions](docs/install-with-codex.md) and [cache cleanup](docs/cache-cleanup.md).

Maintainer: [y15801172513-lang](https://github.com/y15801172513-lang). Issues are initially disabled. No paid service, response deadline or account recovery support is offered.

When diagnosing a problem, share the version and a redacted error, not private project contents, tokens, full local paths or complete installation receipts. Installation, Skill registration and project connection each require their own explicit confirmation.
